      18. เมนูย่อยแถบข้าง (ds-nav__group)

      ตัวจริงอยู่ในแถบด้านข้างของหน้านี้ (เมนู “ตั้งค่า”) · ปุ่ม ds-nav__toggle เป็น ds-nav__item ชนิด <button> จึงหน้าตาเหมือนเมนูปกติ · aria-controls = id ของ ds-nav__sub · เมนูย่อยไม่มีไอคอน · เมื่อแถบข้างย่อเป็นแถบไอคอน 72px เมนูย่อยจะซ่อน และการคลิกปุ่มกลุ่มจะขยายแถบข้างก่อนแล้วจึงเปิดกลุ่ม · กล่องสีกรมท่าด้านล่างเป็นเพียงพื้นหลังจำลองของแถบข้าง

      กลุ่มปิด (ค่าเริ่มต้น) และกลุ่มที่มีหน้าปัจจุบัน — เซิร์ฟเวอร์เรนเดอร์สถานะเปิดเองได้: aria-expanded="true" + has-current + ไม่มี hidden

      ข้อมูลหลัก
      ตั้งค่าบริษัท ตั้งค่าระบบ ผู้ใช้งานและสิทธิ์ บันทึกการใช้งาน
      สรุปงานซ่อมรายเดือน ประวัติซ่อมตามครุภัณฑ์ ผลการประเมินความพึงพอใจ

      19. ช่องเลือกแบบค้นหา (combobox)

      ใช้แทน Select2 สำหรับเลือกค่าเดียว: เขียน <select> ปกติแล้วใส่ data-ds-combobox — ds-ui.js สร้างช่องพิมพ์ค้นหา (role="combobox") ให้เอง · select เดิมยังเป็นแหล่งข้อมูลจริง (id / name / value เดิม, ส่งฟอร์มได้ตามปกติ, เกิด change + input) · รองรับ optgroup และตัวเลือกปิดใช้งาน · พิมพ์เพื่อกรอง, ลูกศรขึ้น/ลง + Enter เลือก, Esc ยกเลิก · ลบข้อความทั้งหมด = เลือกตัวเลือกว่าง (value="") · เพิ่มภายหลัง: DS.combobox.enhance(el)

      ลองพิมพ์ “ไอ” หรือ “สาขา” · ตัวเลือกสีจางเลือกไม่ได้
